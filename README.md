# SmartQueue Management System

A web-based queue management system built using Python, Flask, HTML, CSS, JavaScript, and SQLite.

## About the Project

SmartQueue helps organizations manage customer queues digitally. Customers can generate tokens, check their queue position, and view their estimated waiting time. Administrators can manage the queue through a separate dashboard.

## Features

- Customer token generation
- Automatic token numbering
- Live queue updates
- Queue position and estimated waiting time
- Token search and status tracking
- Admin login and dashboard
- Customer status management
- SQLite database for storing customer records
- Mobile access on the same network

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
